## 注意事项

- **Rare UI**：LICENSE 为 MIT + Commons Clause + 署名。可把组件用进自己的应用 / 网站（含商用），但不能把组件本身单独出售、转授权或再分发（含移植版）；成品须可见署名并链接 https://rareui.com。GitHub 显示许可证为 Other。
- **ExpoKit**：核心组件与 expo-charts 为 MIT 免费；官网写 Pro 为一次性 $29。仓库现为 `ExpoKit/ExpoKit`（旧地址 `Anshkaran7/expokit` 会跳转）。
- **affectUI**：46 项开源免费（MIT）；其余在 Pro。官网（2026-11-10）：Individual 一次性 $249，Team 一次性 $699，含终身更新。
- **goopUI**：README 标明 pre-alpha，尚未上 npm；目前只有 Vue / Nuxt，React / Svelte 仍在计划中。
- **Sketchbook UI**：2026-11-10 查看时有 119 个未关闭 issue。
- **beUI React Native**：单独仓库 [starc007/beui-native](https://github.com/starc007/beui-native)（MIT，Stars 11，2026-11-02 更新），未单独计入总数。
